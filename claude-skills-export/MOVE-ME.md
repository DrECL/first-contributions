# Instructions: move this folder into the claude-skills repo

This folder is the complete starter content for the `DrECL/claude-skills`
repository. It was prepared in a Claude session that could not push to that
repo directly, so it was parked here.

**Any Claude session with access to both repos can finish the job:**

1. Clone or open `DrECL/claude-skills`.
2. Copy everything in this `claude-skills-export/` folder (except this
   MOVE-ME.md file) into the ROOT of the claude-skills repo, keeping the
   folder structure exactly as-is.
3. Commit and push to claude-skills' main branch.
4. Delete this `claude-skills-export/` folder from first-contributions
   and push that cleanup too.

After that, `claude-skills/README.md` explains how every environment
connects to it.
